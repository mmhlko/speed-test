# Измерение скорости скачивания

Требуется Node.js 22 или новее. Сторонние зависимости не нужны.

```sh
node download-speed.mjs "https://example.com/large-image.jpg"
```

Скрипт выполняет ровно 10 последовательных GET-запросов к HTTP/HTTPS-адресу.
Каждый ответ читается полностью перед следующим запросом. Перенаправления
обрабатываются автоматически. Данные читаются потоком и не сохраняются на диск.

В консоли выводятся результаты каждого запроса и итоговые показатели:

- Среднее время запроса в миллисекундах: сумма длительностей / 10.
- Общий объём тел ответов в байтах и мебибайтах (1 МиБ = 1 048 576 байт).
- Скорость скачивания в МиБ/с: общий объём / суммарное время запросов в секундах.

Время измеряется от начала запроса до полного чтения тела ответа и включает
ожидание сервера и установление соединения, если оно необходимо. Вывод в консоль
между запросами в расчёт не входит. Это скорость получения выбранного ресурса,
а не отдельное измерение пропускной способности интернет-канала.

HTTP-заголовки и служебный сетевой трафик в объём не включаются. Скрипт запрашивает
ответ без сжатия (`Accept-Encoding: identity`); если сервер всё же применит сжатие,
учитывается размер распакованного тела, которое возвращает `fetch`.

Лимит времени на каждый запрос, включая чтение тела, — 120 секунд. При неверном
адресе, сетевой ошибке, превышении лимита или HTTP-статусе вне диапазона 200–299
скрипт завершается с кодом 1. Итоговая статистика выводится только после всех
10 успешных запросов.
